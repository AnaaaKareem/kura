# SAST Triage Report (Semgrep and Bandit)

This document records the code review triage of all static analysis findings from Semgrep (`docs/evidence/semgrep.txt`, 28 blocking findings prior to G06; `docs/evidence/2026-12/semgrep-before.txt`, 21 blocking findings after G06) and Bandit (`docs/evidence/2026-12/bandit.txt`, 10 findings across 12,255 lines of non-test Python code).

Every Semgrep finding was inspected in source context. Confirmed issues were fixed in place, accepted design trade-offs received an explicit compensating control and annotation, and false positives received inline `# nosemgrep` comments explaining why the pattern is safe. After triage, `docs/evidence/2026-12/semgrep-after.txt` reports zero un-triaged blocking findings.
