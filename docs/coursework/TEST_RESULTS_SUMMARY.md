## Residual Risks

1. **`python-jose` and `ecdsa` transitive CVEs**: Accepted with documented justification in `.trivyignore`; no upstream patch is available for the pinned dependency chain, and `kura/__init__.py` redirects JWT handling to `cryptography`.
2. **HIBP breach check fails open**: If `api.pwnedpasswords.com` is unreachable, the k-anonymity password check skips the remote lookup so password changes do not lock out legitimate users.
3. **Unfixed Debian base-image OS CVEs**: Some OS-level packages in Debian base layers have no vendor fix available yet (`ignore-unfixed: true` in `.github/workflows/security.yml`).
4. **Single-VM prototype availability**: All services run on one host without database, Vault, or Loki high-availability failover.
5. **External Gmail SMTP dependency**: Outgoing email delivery relies on an external mail relay.
6. **Self-signed public TLS certificate**: The local prototype serves a self-signed certificate on port 443 (`testssl.sh` grade T); production requires a trusted CA certificate.
7. **Human factors and credential phishing**: Technical controls reduce impact through MFA and passkeys, while user awareness and phishing resistance still depend on ongoing training.
8. **T14 restore drill scope**: The restore drill validated seeded demo data (8 users, 1 course, 2 enrollments, 1 assessment, 0 grades) on a disposable volume and did not run a full multi-host disaster recovery exercise.
9. **Manual external active testing pending upload**: Active scanning outputs for `T4` (`zap-full-scan.py`), `T5` (`sqlmap`), `T7` (`ffuf`), `T8` (`hydra`), `T10` (`nmap -sV -p-`), `T17` (`nmap --script vulners`), and `T18` (`nikto`) are executed manually by the operator and will be parsed into `docs/evidence/security-tests/TEST_LOG.md` once placed in `docs/evidence/security-tests/`.
10. **Historical credentials in early git history**: Gitleaks (`ST-07`) detects the revoked Gmail App Password in commit `b0dd739d` (redacted in `4e63762`) and disposable dev `VAULT_SECRET_ID` in commits `e8cdfb9c` and `c547d752` (moved to Docker secrets in `bcd8ff0` and rotated). Both credentials are invalidated, and `HEAD` (`ST-09`) contains zero secrets, though rewriting git history would require `git filter-repo` and force-push coordination.
11. **Optional gap G16 not implemented**: Internal mTLS CRL revocation checking (P3) was left out of prototype scope.
