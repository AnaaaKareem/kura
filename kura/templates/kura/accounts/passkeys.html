Ways to add a passkey

When you click Add a Passkey, your browser lets you choose one of these:

  • Windows Hello (face, fingerprint or PIN)
  • Apple Passwords / iCloud Keychain, Touch ID or Face ID
  • Google Password Manager or another password manager that supports passkeys
  • Your phone, by scanning the QR code the browser shows
  • Physical security key (such as a YubiKey): optional, choose it only if you own one
